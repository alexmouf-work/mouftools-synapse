# Favicon, app icon, installable web app (built 2026-11-04)

Principal: "create a favicon and app icon using the grid cell icon. make sure it's compatible with being turned into a
web app. it should be called \"Synapse\""

- The grid-cell symbol, flat: seven teal discs (#3fb3a3), a centre and six round it (ring 0.78, disc 0.30, as in
  the designer's 3-D symbol). Source SVGs drawn by code; PNGs rendered from them.
- `public/favicon.svg` (transparent, for tabs) and `favicon.ico` (16/32/48); `apple-touch-icon.png` 180 px on the dark
  board colour (#15181e); `icons/icon-192.png` and `icon-512.png`; `icons/icon-maskable-512.png` with the discs inside
  the 40% safe circle.
- `public/site.webmanifest`: name and short name "Synapse", standalone, landscape (phones play sideways), start and
  scope "/", dark background and theme. Every page links the icons and manifest, with "Synapse" as the home-screen
  title on iOS and Android and light/dark theme colours.
- Installable: Chrome and Edge also want a service worker for the install prompt; Safari and Android's "Add to Home
  Screen" work without one. Offline play would need a service worker that caches the build: a later step.
- Check: `npm run check:icons` (in `npm run check`).
