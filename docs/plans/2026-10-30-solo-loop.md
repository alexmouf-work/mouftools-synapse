# Synapse — solo loop (milestone 1): build plan

Status: approved 2026-10-30 ("go for it"); builder menu mock-up first. Synapse is a sandbox (ruling 2026-10-30); this
milestone is its first arena, racing, and still needs re-framing around the workbench as home. Milestone: one human vs 4 bots, no server, desktop,
static site at synapse.mouftools.com. Rulings live verbatim in `docs/CONTEXT.md`; this plan links, never restates.

## 0. Stack
Vite + TypeScript + Three.js (npm, r160+), Vitest, no backend. Two additions:
- **Playwright (dev only)** — render smoke check; the mock-up's trap (one NaN pixel + UnrealBloom = black frame)
  only shows in a real WebGL frame.
- **Self-hosted fonts** (@fontsource Chakra Petch, IBM Plex Mono) — no CDN dependency, no layout shift.

## 2. Main types (sketches)
- Pins are fixed and always present (ruling 2026-10-30); an input costs energy only while it has a wire. Car inputs:
  6 eyes (left, front-left, front, front-right, right, back: 8 directions minus the back diagonals), speed, road ahead,
  bias. Outputs: steer, throttle.
- `BrainSpec = {v:1, nodes:{id, x, y, act, dropout}[], conns:{from,to}[]}` — neurons are free-placed on the workbench
  (x, y are layout only); ids stable, never reused; pins are implicit. Any wire that keeps the graph loop-free is legal.
  A node's layer = its longest-path depth from the inputs, derived, never stored; span = depth difference.
  `act ∈ step|relu|sigmoid|tanh` (none on sensors/bias). `dropout` = 0, reserved; validator rejects others this milestone.
- `Genome = {spec, w:number[]}` aligned to conns; canonical JSON (doubles round-trip exactly); `genomeHash` over both.
- Compiled: topological Int32 from/to arrays + Float64 weights; bias node = constant 1.
- `Track = {seed, pts (x,y every 2 m), tan, curv, len, wallOff, grid, pads[], gates[], startIdx}`. Elevation and
  scenery are render-only, derived from the seed in the client.
- `CarState = {x,y,hdg,v, idx, prog, maxProg, wallTicks, energyPrev, noiseA, rng}` — all Float64; no Float32 in the sim.
- `MatchState = {seed, round 1..5, phase: build|train|compete|upgrade|final, endsAt, racers[5], results[]}`;
  `Racer = {id, name, kind: human|bot, genome, points}`. Pure `step(state, event)`; events `clock`, `lockBrain`,
  `trainingDone`, `raceDone`. Multiplayer later swaps the clock source and relays events.
- **Energy per tick:** used = Σ sensor cost + Σ neuron upkeep(act) + Σ conns c_fire·|out_from·w|·(1 + skip·(span−1)).
  a = clamp(used_prev/budget − 1, 0, 1); every node output → (1−a)·clean + a·U(−1,1) from the car's seeded stream,
  applied after the transfer function.

## 3. Numbers (all in config.ts)
- **Tick:** brain 20 Hz; physics 2 substeps/tick (dt 0.025 s); renderer interpolates.
- **Budget (E/tick):** R1 10 · R2 14 · R3 20 · R4 26 · R5 32.
- **Costs:** eye 0.6 · speed 0.3 · road ahead 0.6 · bias 0 (inputs charged only when wired) · c_fire 0.1 · skip +0.5 per extra layer spanned · weights ±4.
  Neuron upkeep by transfer function (hidden / output): step 0.2/0.1 · ReLU 0.25/0.15 · sigmoid 0.5/0.3 · tanh 0.5/0.3.
- **Transfer functions:** step = 1 if x>0 else 0 · ReLU capped at 4 · sigmoid 1/(1+e^−x) · tanh — all via fmath.
  Outputs read as clamp(v,−1,1); step/sigmoid/ReLU outputs remapped 2v−1 so any choice can steer both ways.
- **Presets:** Starter = the five front-facing eyes + speed + road + bias → 4 neurons → outputs, sparse (≈6/10, as the
  builder mock-up) · Minimal = front-left, front, front-right + road → outputs · Deep.
- **Caps:** 40 neurons, depth 4.
- **Sensors:** eye range 80 m, input 1 − d/80 · speed v/60 · angle = signed angle to the centreline 30 m ahead, /π
  (invisible checkpoints every 30 m; visible gates are cosmetic).
- **Car (arcade):** accel 14·throttle; brake 30·|throttle| when throttle<0, no reverse; drag 1.5 + 0.0035·v² (top
  ≈60 m/s); yaw rate steer·v/12 m capped by 24 m/s² lateral grip (capped → scrub ≤6 m/s²). Walls 12.5 m from centre
  (11.5 m for the car centre): clamp back, v×0.6, heading eased to tangent, wall tick. Boost pad (|offset|<4.2):
  +10 m/s, cap 72, once per pad per lap; not sensed.
- **Track generator:** closed centripetal Catmull-Rom through K∈[8,14] points; angles even ±30% jitter; radius
  R∈[170,260] m × U(0.55,1.0) per point; resampled every 2 m. Valid iff length 1100–1900 m, min radius 25 m (curvature
  smoothed over 10 m), parts >60 m apart along the track are ≥31 m apart in space, a ≥150 m straight (start at its
  middle), 2–3 pads on the calmest 30 m windows ≥300 m apart. Failure → next sub-seed; 200 failures → throw.
- **Seeds:** match seed → per round 2 training tracks + 1 unseen compete track + noise streams. `?seed=` reproduces.
- **Experience budget:** T = 3,000,000 simulated car-ticks per racer per training phase, the same for every trainer
  (≈60 neuroevolution generations). The metered env throws on overrun; a trainer reaches the sim only through it.
  Fixed in step 1 as the largest multiple of 0.5M that neuroevolution spends within 7 s in Chrome on the reference
  desktop, clamped 1.5M–6M.
- **Neuroevolution:** population 64; 2 training tracks × 20 s (400-tick) episodes; elitism 4; tournament k=3; no
  crossover. Mutation: each weight p=0.2 by N(0,σ), σ linear 0.4→0.08 over the phase; reset p=0.01 to N(0,1); clamp ±4.
  R1 initial N(0,0.5). Later rounds: slot 0 = carried champion exactly, 1–63 its mutants; new conns start at 0.
  Common random numbers per (phase, track); ties by index; results gathered by index so the worker split can't matter.
  Stops when the next worst-case episode wouldn't fit T; generation count is a result, not a setting.
- **Fitness:** cumulative centreline progress (m; backwards subtracts), mean over 2 tracks, −0.5 per wall tick. Episode
  ends early on stall (max progress +<5 m in 3 s) or progress < −20 m.
- **Compete:** all 5 cars start on the same pose (ghosts). 600 ticks precomputed at phase start (~15 ms), frames and
  activations recorded, played back on the clock. Rank by progress at 30 s.
- **Scoring:** 10/7/5/3/1 per round; ties broken by best R5 finish, then R4, …
- **Worker pool:** min(cores − 1, 4). Not done at 10 s → "overtime" showing ticks used/T; results never depend on speed.
- **Bots** (designs as data; upgrade at phase start; **train in the background during the player's build/upgrade
  phase** with the same T and seeds, so the player's 10 s gets the CPU):
  - **Minimalist** (white/red): R1 front-left, front, front-right + road → outputs; R2 +3 neurons; R3 +left, right; R4 +speed; ≤75% budget.
  - **Big Brain** (pink, tanh): R1 all 6 eyes + speed + road → 8 → 6 full ≈140% budget (heavy static);
    grows into it by R4–5.
  - **Twitchy** (cyan, step): front three eyes + speed → 4, skip wires eyes→steer; R3 +left, right.
  - **Lazy Eye** (green): left, front-left, front + road → 6; R3 +back. Never looks right.

## 3b. Trainer seam (only neuroevolution built this milestone)
- `Trainer { id; channels; init(genome, seed, env); step(tickAllowance) → TrainerEvent[]; weights() → Genome;
  probe() → ProbeFrame }`. Events: generation/episode done, fitness or loss stats, ticks used. Architecture is fixed;
  a trainer changes weights only (spec hash must not change).
- `Env { runEpisodes(policies[], tracks) }` (parallel, pooled) and `stepCar(policy, actionNoise)` (one car, one tick);
  both seeded and metered. Exploration noise exists only in training; races are deterministic.
- **Probe channels** for the brain panel: `signal` (sender output × weight; all trainers) · `delta` (per-connection
  gradient/δ; backprop) · `reward` (per tick; A_RP) · `value` + `td` (actor-critic). The panel draws what a trainer
  declares and fails loudly if a declared channel is missing.
- **Later trainers the seam must fit** (order set by the principal: backprop, actor-critic, A_RP):
  backprop imitating a teacher (scripted pure-pursuit driver in `sim/teacher.ts`, metered like any car; later a lap
  the player drives) · actor-critic (critic is a separate trainer-owned net; never races, no energy cost) · A_RP with
  the delta rule (stochastic units inside the env). A gradient trainer declares which transfer functions it supports;
  the editor warns when the brain uses one it can't train (step has no gradient).
- In a match the trainer is part of each player's build (principal 2026-10-30); the picker appears once a second
  trainer exists.

## 4. Steps
Each step ends with all checks green, a commit, docs in the same commit, and (from step 2) a preview deploy. The race
view comes before the editor so every later step can be seen.

### Step 1 — headless sim + evolution benchmark (GO / NO-GO)
- **Build:** repo skeleton + docs; config, rng, fmath, hash; track, car, sensors, brain (4 transfer functions),
  energy, race; train/ (interface, metered env, neuroevo); `scripts/sim/bench.ts` (Node worker_threads, same split
  logic as the browser); dev-only `/bench` page running the same benchmark in Chrome.
- **Pass criterion** (seeds 1–20, Starter brain, R1 budget, one phase's T):
  (a) median progress of the end-of-budget champion on the round's unseen 30 s track ≥ 3× the gen-1 champion's;
  (b) it covers ≥ 80% of a lap on ≥ 15/20 seeds;
  (c) best training fitness at the end ≥ 2× gen 1 on 20/20;
  (d) Minimal preset covers ≥ 50% of a lap on ≥ 15/20 (cheap designs are viable);
  (e) the phase finishes in ≤ 7.0 s in Chrome `/bench` on the reference desktop (4+ cores, ≈2020 i5/Ryzen 5/M1);
  (f) same seed → same hash; 1 worker vs 4 → same hash.
- **If it fails, levers in order** (report before each): 15 s episodes · more grip / wider road · σ schedule ·
  population 48 × more generations · evolution-strategies update. All fail → NO-GO, rethink.
- **Checks:** unit — 1000 track seeds valid; hand-computed brain outputs for every transfer function; energy maths
  incl. skip surcharge and overage → a; **upgrade invariance** (adding w=0 conns or neurons leaves every recorded output
  identical over 600 ticks, for all four transfer functions); genome JSON round-trip hash-identical; a car crossing a
  wall never ends outside it · trainer contract suite (spends exactly within budget, same seed → same hash, weights()
  keeps architecture, ticks monotonic, declared channels present) · purity (src/common: no DOM/three, no Math.random,
  Date, performance, Math.sin/cos/tan/atan2/exp/tanh/pow, Float32Array) · determinism golden hashes (3 seeds) ·
  bench Node time ≤ baseline ×1.3.
- **Reviewer looks at:** the bench table (fitness per generation per seed); an SVG per seed of the gen-1 / mid / final
  champion paths on the unseen track (written to ignored `out/`); `/bench` time. Paths that don't visibly go from
  crashing to lapping = NO-GO.

### Step 2 — race view (renderer port, sim-driven) + Vercel from day one
- **Build:** port the mock-up into `src/client/render` module by module, driven by `Track` + recorded frames: ribbon,
  kerbs, walls, pads, gates, terrain, trees, cars, real sensor beams, cameras (chase / broadcast / showroom). Brain panel
  draws probe channels; static from the real a. Tick interpolation. A car is drawn translucent while it overlaps another
  (ghosting must read). Vercel project with a preview per push; synapse.mouftools.com CNAME → cname.vercel-dns.com.
- **Checks:** Node test — geometry builders produce no NaN vertices for 200 seeds · every InstancedMesh write asserts
  count ≤ capacity and throws · dev builds throw on non-finite sim state · **render smoke** (Playwright, SwiftShader):
  `/?seed=1&view=race`, after 3 s mean luminance above threshold, frame not uniform, console clean; frame time logged.
- **Principal looks at:** the preview URL beside the mock-up — still "FIRE"? Do step-1 cars drive believably, rays hit walls?

### Step 3 — brain editor
- **Build:** the plain workbench of `reference/builder-mockup.html` (approved look follows the principal's verdict): fixed
  pins on the edges, free-placed neurons, drag from a dot to wire, click a wire to cut, Tidy, per-neuron transfer function
  with its cost, energy battery, presets. Sandbox first: no race styling here.
  Live energy bar: exact static cost + firing estimate from the champion's measured mean ("est."). All edits are pure
  ops in `common/sim/brain.ts`.
- **Checks:** edit-op tests (ids stable, forward-only, caps, full-connect counts, removal drops dependent conns) ·
  editor cost === energy.ts (same function, asserted) · Playwright: one drag = one conn; shift-drag = layer×layer.
- **Principal looks at:** can you build a brain you like in 60 s? Is shift-drag discoverable? Is the cost believable?

### Step 4 — training in workers + training view
- **Build:** pool over the trainer; after each generation the worker posts fitness stats, champion genome and all 64
  paths on track 0 (5 Hz, transferable Float64). View: the mock-up's training camera and ghost swarm, latest generation
  played ~8×, live fitness graph, "ticks used / T · gen n", overtime state.
- **Checks:** Playwright `/bench?workers=1` vs `?workers=4` → identical hash · ghost count ≤ capacity assert ·
  browser bench on the review checklist.
- **Principal looks at:** one 10 s phase — does it read as learning (crashes, then streaming through corners)?

### Step 5 — match loop
- **Build:** reducer + solo clock; R1 build 60 → train 10 → compete 30; R2–5 upgrade 30 → retrain 10 → compete 30;
  round results overlay during the next upgrade phase (adds no time); final podium; weights carried; `?seed=`. Bots are
  Starter copies until step 6.
- **Checks:** reducer tests with a fake clock (exact order and durations, 380 s total) · a no-op upgrade keeps the genome
  hash · `scripts/sim/match.ts` runs a full headless match with a stable final hash.
- **Principal looks at:** one full match — timers right? Clear what to do in each phase?

### Step 6 — bots
- **Build:** the four designs above as data, upgrade scripts, background training during build phases.
- **Checks:** every bot spec valid each round and its static cost within its intended band (test table) · balance run,
  50 headless matches vs a scripted "Starter + sensible upgrades" player: each bot wins ≥1, none >50%, scripted player's
  median finish 2nd–4th; report committed with the change.
- **Principal looks at:** two races — can you tell the personalities apart by their driving alone?

### Step 7 — scoring, HUD, scouting
- **Build:** points and standings; phase chip (name, round, ticks/gen, time); click a racer (row or car) to scout their
  brain lighting up with their energy and static; camera and ray toggles, keys 1–4; seed on the results screen.
- **Checks:** scoring tests (ties, totals) · Playwright: clicking a row switches the panel's name and node count to that
  racer's spec · HUD energy text equals that tick's recorded energy.
- **Principal looks at:** can you read a rival's brain mid-race? Is static legible as "over budget"?

### Step 8 — production hardening + milestone pass
- **Build:** production domain, cache headers, quality toggle (DPR cap, shadow size, bloom on/off), loading screen,
  WebGL-missing message.
- **Checks:** full suite · render smoke against production · manual smoke in Chrome, Firefox, Safari desktop + one
  laptop iGPU at ≥ 50 fps on default quality.

## 5. Risks (how each is caught early)
1. **Evolution doesn't visibly learn in the budget** — step 1 go/no-go on an unseen track (overfitting shows).
2. **Training too slow on typical desktops** — fixed T keeps it fair; bots train during build phases; bench budget
   check + `/bench` on the reference machine; overtime state instead of a silent cut.
3. **Determinism drift** (engine Math.*, Float32, sort ties, worker split) — fmath + purity check, golden hashes,
   1-vs-N worker hash. Strict now because multiplayer will re-simulate races on every client.
4. **NaN → black frame** — finite asserts, InstancedMesh capacity asserts, Node geometry NaN test, pixel probe.
5. **Energy balance off** — bench sweeps, bot cost table, 50-match balance report; every number in config.ts.
6. **Bad generated tracks** — validator + 1000-seed property test; generator fails loudly.
7. **Editor too fiddly for 60 s** — presets first; Playwright interaction tests; principal's step-3 play.
8. **Renderer port is large (~1000 lines)** — module by module behind render smoke; mock-up kept in `reference/`.
9. **Later gradient trainers learn tick by tick** and won't spread across workers — may run past 10 s even under a fair
   T. Overtime covers it; results don't depend on speed; each new trainer must pass the contract suite + a wall-time bench.

## 8. Calls made without asking (2026-10-30; overturn freely)
- Round results shown as an overlay during the next upgrade phase (adds no time).
- Bots train in the background during the player's build phase (same result, saves CPU).
- R5 not worth double points.
- The experience budget counts car-ticks, not brain evaluations.
